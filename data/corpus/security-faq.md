# Security FAQ

All customer data is encrypted at rest using AES-256 and in transit using TLS 1.3.

We are SOC 2 Type II certified and undergo an annual third-party penetration test.
Audit reports are available to Enterprise customers under NDA.

Two-factor authentication is available on all plans and is enforced by default for
Enterprise workspaces. Single sign-on (SSO) via SAML is available on the Enterprise plan.
